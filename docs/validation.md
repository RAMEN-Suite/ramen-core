# Validation

Check model definitions with {@link model.Modeller.validate | validate()}.
Check captured data with {@link model.Modeller.validateInstances | validateInstances(data)}.
Both return findings as [Diagnostics](diagnostics.md).

See [Validate the model](rmf.md#validate-the-model) for a first example.
